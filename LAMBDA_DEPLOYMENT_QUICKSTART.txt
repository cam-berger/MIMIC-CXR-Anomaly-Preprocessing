MANUAL DEPLOYMENT (Step-by-Step)
================================================================================

If you prefer manual control or the automated script fails:

Step 1: Transfer Files to Lambda
---------------------------------
From your local machine:

# Transfer validation data (~1.2 GB compressed)
rsync -avz --progress -e "ssh -i /home/dev/Downloads/berger-cm.pem" \
  validation_data_subset.tar.gz ubuntu@192.222.57.66:~/

# Transfer code (~56 MB)
rsync -avz --progress -e "ssh -i /home/dev/Downloads/berger-cm.pem" \
  step2_preprocessing.tar.gz ubuntu@192.222.57.66:~/

# Transfer Lambda config
scp -i /home/dev/Downloads/berger-cm.pem \
  step2_preprocessing/config/config_lambda.yaml ubuntu@192.222.57.66:~/

Step 2: Setup Lambda Instance
------------------------------
SSH into Lambda:

ssh -i /home/dev/Downloads/berger-cm.pem ubuntu@192.222.57.66

Create directories:

mkdir -p ~/data ~/output ~/code ~/output/checkpoints

Extract files:

tar -xzf validation_data_subset.tar.gz
mv validation_data_subset/* data/
rmdir validation_data_subset

tar -xzf step2_preprocessing.tar.gz -C code/

Step 3: Setup Python Environment
---------------------------------
cd ~/code
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt

# Install scispacy model (takes 5-10 min)
pip install https://s3-us-west-2.amazonaws.com/ai2-s2-scispacy/releases/v0.5.1/en_core_sci_md-0.5.1.tar.gz

Step 4: Configure Paths
------------------------
cp ~/config_lambda.yaml ~/code/step2_preprocessing/config/config.yaml

Step 5: Set Environment Variables
----------------------------------
export CUDA_VISIBLE_DEVICES=0
export ANTHROPIC_API_KEY='your-api-key-here'

Step 6: Verify Installation
----------------------------
python3 -c "import torch; print(f'PyTorch: {torch.__version__}, CUDA: {torch.cuda.is_available()}')"
python3 -c "import spacy; nlp = spacy.load('en_core_sci_md'); print('scispacy loaded')"
python3 -c "import h5py; import pyarrow; print('h5py and pyarrow loaded')"
nvidia-smi  # Verify GPU

Step 7: Run Pre-compilation
----------------------------
cd ~/code
source venv/bin/activate

python run_precompilation.py \
  --config step2_preprocessing/config/config.yaml \
  --split val \
  --max-samples 200 \
  2>&1 | tee ~/output/precompilation.log

- Claude summarization: 2-4 hours (longest step)

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "ANTHROPIC_API_KEY not set"
Solution: Export your API key before running
  export ANTHROPIC_API_KEY='your-key-here'

Issue: "CUDA out of memory"
Solution: Reduce batch size in config.yaml
  processing.batch_size: 1  (should already be set)

Issue: "scispacy model not found"
Solution: Reinstall scispacy model
  pip install https://s3-us-west-2.amazonaws.com/ai2-s2-scispacy/releases/v0.5.1/en_core_sci_md-0.5.1.tar.gz

Issue: "Cannot connect to Lambda"
Solution: Check SSH key permissions
  chmod 400 /home/dev/Downloads/berger-cm.pem

Issue: Pre-compilation takes too long (>8 hours)
Solution: Check if Claude API is responding
  - Verify API key is valid
  - Check Claude API status
  - Consider disabling summarization temporarily in config.yaml:
    text.summarization.use_claude: false

Issue: Low validation success rate (<95%)
Solution: Check precompilation.log for specific errors
  - Missing MIMIC-IV data: Check data paths in config.yaml
  - CXR-PRO errors: Expected ~1% missing (197-199 success is OK)
  - Claude API errors: Check API key and quota
