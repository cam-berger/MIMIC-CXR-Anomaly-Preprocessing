# v3: TypeSafe's Jev on MIMIC-CXR

In v3 we asked whether Jev, a hosted classification model from TypeSafe, could
improve on what v2 built for the 12 MIMIC-CXR findings. We gave it three jobs.
First it was the final classifier, reading v2's image-model estimates and the
text written before the X-ray. Then it labeled radiology reports. Last, its
labels were used to train v2's image model. Each step's question and pass rule
went into [`V3_PLAN.md`](V3_PLAN.md) before the step ran. Scores are macro
AUROC on v2's benchmark, the official MIMIC-CXR split, unless a step says
otherwise.

## What we found

Jev didn't beat v2's simpler tools at any of the three jobs.

As the final classifier it scored 0.803 on the official test set. A logistic
regression fit on the validation split, given the same inputs, scored 0.827.
The text did nothing for Jev. Adding the indication, the ED chief complaint and
the prior report moved it by -0.002, while the same text adds about +0.012
through the logistic regression. Showing Jev the X-ray didn't help either
(-0.001). Reading the X-ray on its own, Jev scored 0.716. v2's fine-tuned
RAD-DINO scores 0.814.

As a report labeler, Jev ended up further from a radiologist's labels than the
CheXpert labeler did: 0.914 against 0.940 on 596 studies. Almost all of the gap
is Lung Opacity. Our question to Jev defined it as any area of increased lung
density, so Jev marked it present in 404 of those studies. The radiologist
marked 146.

Jev's labels looked better as training data at first. A small model (a linear
probe on frozen RAD-DINO features, 20,000 training studies) trained on Jev's
labels did about as well as one trained on CheXpert labels when the MIMIC
radiologist judged it (+0.009, within noise). On the CheXpert test set from
Stanford it did much better (+0.065). That gain came from how two findings are
defined. Stanford's radiologists mark Lung Opacity whenever they mark
atelectasis, consolidation, edema, a lesion or pneumonia, and Enlarged
Cardiomediastinum whenever they mark cardiomegaly. Jev's broad questions come
close to doing the same, and the CheXpert labeler doesn't. Applying that rule
to the CheXpert labels, with no Jev involved, recovered +0.053 of the +0.065.

The last step, v3.8, retrained v2's main model on all 213,357 training studies
three times: with the CheXpert labels, with the CheXpert labels plus the rule,
and with Jev's labels. Each version was trained with two seeds. On the CheXpert
test set Jev's labels came out level with the rule, +0.005 for both seeds,
right at the edge of what this test set can detect. On the MIMIC radiologist's
studies they came out level with the plain CheXpert labels (+0.001 and
+0.002). Neither of the two pre-registered tests passed.

| Training labels | CheXpert test set (6 findings) | MIMIC radiologist (10 findings) |
|---|---|---|
| CheXpert labeler | 0.871, 0.874 | 0.810, 0.814 |
| CheXpert labeler with the rule | 0.921, 0.919 | 0.796, 0.798 |
| Jev | 0.926, 0.924 | 0.811, 0.815 |

The two numbers are the two seeds. v2's original runs of the same model score
0.869 and 0.874 on the CheXpert test set and 0.809 and 0.813 on the MIMIC
radiologist's set, so retraining reproduced them.

One thing in that table wasn't among the pre-registered tests, but it's worth a
closer look. The rule that helps on Stanford's labels costs 0.015 on the MIMIC
radiologist's, for both seeds, because that radiologist doesn't label this way.
Jev's labels are the only ones that match the best option on both test sets.
If you don't know how the people judging a model define these findings, Jev's
labels may be the safer choice. We haven't tested that directly.

In practice, v2's model trained on the CheXpert labels stays the baseline. If
it will be scored against labels that follow the hierarchy, apply the rule to
the training labels first. That's one line of code and needs no outside
service.

advance. In v3.8 a test passes only if the intervals for both seeds are above
zero. v3.4 tried cut-offs on Jev's probabilities as labels. That brought it to 0.931
against the radiologist, within noise of the CheXpert labeler's 0.940.

## How it was run

Nothing was chosen on a test set. The validation split picked the question
format: plain yes/no questions beat a ten-band likelihood scale. Jev was pinned at version `jev-1.14.0`,
and every answer came from that version. The requests sent MIMIC report text,
and in v3.1 the X-rays, to TypeSafe. We confirmed TypeSafe keeps no data
before sending any. All scores come from v2's evaluation code, with confidence
intervals from a bootstrap over patients. Besides the automatic labels, there
were two judges: a radiologist's labels for 596 official-test studies, and the
CheXpert test set (500 Stanford studies, each labeled by five radiologists).

Jev received about 470 million input tokens in all. 400 million of them went to
labeling the 213,357 training reports (v3.5 and v3.8). The six v3.8 fine-tunes took 7.5 hours
on one H100.
