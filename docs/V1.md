# v1: the from-scratch multimodal pipeline

v1 is the project's first version. It builds patient cohorts from four MIMIC datasets, preprocesses chest X-rays, labs, vital signs and text, pretrains a masked autoencoder (MAE) on normal X-rays, and trains a multimodal classifier for 12 CheXpert findings on abnormal X-rays. It also scores anomalies by MAE reconstruction error. The December 2025 production run trained the classifier for 50 epochs on one Lambda Cloud GH200 GPU in about 36 hours, for about $54, and reported macro AUROC 0.701 and macro AUPRC 0.899 on its 4,922-study validation set. v2 later re-read that evaluation: four classes have too few negatives to measure, the other eight average 0.792, and three evaluation choices can inflate that number ([details](#what-v2-found-about-v1s-evaluation)). The v1 code is `src/` plus the root scripts `build_cohort.py`, `preprocess.py`, `train_mae.py`, `train_classifier.py` and `detect_anomalies.py`. v2 (`v2/`, [ANALYSIS.md](ANALYSIS.md)) does not change it.

## Data

| Dataset | Version | Used for |
|---|---|---|
| MIMIC-CXR-JPG | 2.1.0 | Images, CheXpert labels, image metadata |
| MIMIC-IV | 3.1 | Age and sex, labs, hospital diagnoses and procedures |
| MIMIC-IV-ED | 2.2 | ED stays, triage, vital signs, ED diagnoses |
| CXR-PRO | 1.0.0 | Report impressions with references to prior studies removed |

All four need PhysioNet credentialed access. Records link through `subject_id` (patient), `study_id` (X-ray study), `dicom_id` (image), `stay_id` (ED stay) and `hadm_id` (hospital admission).

## Pipeline

### 1. Build cohorts

```bash
python build_cohort.py --normal-only      # cohort for MAE pretraining
python build_cohort.py --anomalous-only   # cohort for the classifier
```

This writes `output/cohorts/{normal,anomalous}_{train,val}.parquet`. Each cohort is split by patient into 85% train and 15% validation (`--validation-fraction`), with seed 42.

- **Normal:** CheXpert No Finding = 1 and no pathology = 1; taken within 24 hours of an ED stay; an ED disposition of home, discharged, left (without being seen or against medical advice) or other; no critical diagnosis (sepsis, pneumonia, myocardial infarction, respiratory failure, ARDS, pulmonary embolism) in the ED or hospital record; age 18 or older.
- **Anomalous:** at least one of the 12 pathologies = 1; age 18 or older. For a patient with ED stays, a study stays in only if it was taken within 24 hours of one, and that stay's data is attached. The cohort has 32,498 studies: 27,576 train and 4,922 validation.

Other flags: `--no-ed-match`, `--no-disposition-filter`, `--no-reports`, `--output-dir`, `-v`.

### 2. Preprocess

```bash
python preprocess.py --cohort output/cohorts/normal_train.parquet --workers 8
python preprocess.py --cohort output/cohorts/normal_val.parquet --workers 8
python preprocess.py --cohort output/cohorts/anomalous_train.parquet --leak-free --workers 8
python preprocess.py --cohort output/cohorts/anomalous_val.parquet --leak-free --workers 8
```

Each run writes `output/preprocessed/<cohort name>/`. Without `--cohort`, `preprocess.py` processes every cohort in `output/cohorts/` with the same flags.

- **Images:** one JPG per study (one whose file name contains `PA`, else `AP`, else any JPG in the study folder), kept at full resolution, converted to grayscale and min-max scaled to [0, 1].
- **Structured data:** age and sex, triage vitals and acuity, ED vital signs aggregated over the stay, and 17 labs aggregated from 48 hours before to 24 hours after the X-ray.
- **Text:** the CXR-PRO report. With `--leak-free`, a clinical-context string replaces it: age, sex, chief complaint, triage vitals and acuity, nine lab values, ED and hospital diagnosis codes, procedure codes and ED disposition. `--enable-summarization` has Claude (`claude-sonnet-4-5-20250929`) summarize the text. The result is tokenized with the `emilyalsentzer/Bio_ClinicalBERT` tokenizer, up to 512 tokens.

`--leak-free` exists because CheXpert labels are extracted from the radiology report by an NLP labeler, so a classifier that reads the report can copy its labels. Use it for every cohort the classifier trains or validates on. The MAE reads only images.

Other flags: `--images-only`, `--structured-only`, `--text-only`, `--no-context`, `--cohorts-dir`, `--output-dir`.

### 3. Pretrain the MAE

```bash
# Quick check
python train_mae.py --config debug --train-dir output/preprocessed/normal_train \
    --epochs 2 --batch-size 2 --skip-anomaly

# Full run at 1024 px
python train_mae.py --config base \
    --train-dir output/preprocessed/normal_train \
    --val-dir output/preprocessed/normal_val \
    --img-size 1024 --epochs 800 --batch-size 4 --skip-anomaly
```

This writes `output/models/mae_final.pt`, `mae_best.pt` (lowest validation loss, checked every 10 epochs), `config.json` and `training_history.json`, with checkpoints every 50 epochs in `output/checkpoints/`. Without `--skip-anomaly` it then fits an anomaly detector on the training images (step 5). `--resume` continues from a checkpoint.

### 4. Train the classifier

The production command, as recorded:

```bash
python train_classifier.py --config base \
    --train-dir output/preprocessed/anomalous_train \
    --val-dir output/preprocessed/anomalous_val \
    --chexpert-csv /path/to/mimic-cxr-jpg/2.1.0/mimic-cxr-2.0.0-chexpert.csv.gz \
    --mae-checkpoint output/models/mae_final.pt \
    --epochs 50 --batch-size 16 --img-size 1024
```

`--train-dir` and `--chexpert-csv` are required. Other overrides: `--lr`, `--freeze-mae-epochs` (100 keeps the MAE frozen), `--cls-weight`, `--clip-weight`, `--supcon-weight`, `--num-workers`, `--resume`. The script validates after every epoch, saves the epoch with the best validation macro AUROC as `output/models/classifier_best.pt` and the last epoch as `classifier_final.pt`, and writes `classifier_history.json` and `classifier_config.json`.

The labels are the 12 CheXpert pathologies: Atelectasis, Cardiomegaly, Consolidation, Edema, Enlarged Cardiomediastinum, Fracture, Lung Lesion, Lung Opacity, Pleural Effusion, Pleural Other, Pneumonia, Pneumothorax. A 1 is positive and a 0 negative. Uncertain (`-1`) and blank labels are left out of the loss and the metrics.

### 5. Detect anomalies

```bash
python detect_anomalies.py --image path/to/xray.jpg --model output/models/mae_final.pt --visualize
python detect_anomalies.py --hdf5 output/preprocessed/anomalous_val \
    --model output/models/mae_final.pt --output scores.json
```

The score is the MAE's reconstruction error, and an image above `--threshold` (default 0.05) is flagged as anomalous. `--hdf5` takes a preprocessed directory (the one holding `images.h5`), and `--directory` takes a folder of image files. The script feeds 224 px inputs, so `--model` must be an MAE trained at the default 224 px. The detector that `train_mae.py` fits combines reconstruction error (weight 0.4), k-NN distance (0.3) and a Gaussian-mixture score (0.3) on MAE embeddings, sets its threshold at the 99th percentile of the training scores, and saves it as `output/models/anomaly_detector.pt`. `MultimodalEnsembleDetector` in `src/models/anomaly.py` adds the classifier's confidence and entropy; no script calls it.

## Architecture

### MAE (`src/models/mae.py`)

| Part | Setting |
|---|---|
| Encoder | ViT-Base/16: 768 dimensions, 12 blocks, 12 heads. It sees only the visible 25% of patches. |
| Decoder | 512 dimensions, 8 blocks, 16 heads: smaller than the encoder (the asymmetric design) |
| Masking | 75% of patches, chosen at random per image |
| Loss | Mean squared error on the masked patches, each patch normalized to zero mean and unit variance |
| Input | Center crop of the full-resolution image (a 1024 px crop covers about 13% of a 3056×2544 image), copied to 3 channels, ImageNet normalization |
| Augmentation | Horizontal flip, rotation up to 15°, Gaussian blur with probability 0.5 |
| Embedding for other uses | CLS token from the encoder run on the whole unmasked image (768) |

### Classifier (`src/models/multimodal.py`, `src/models/losses.py`)

| Part | Setting |
|---|---|
| Image encoder | The MAE encoder (always ViT-Base/16), CLS token → 768. Frozen for the first `freeze_mae_epochs` epochs. |
| Text encoder | `microsoft/BiomedNLP-PubMedBERT-base-uncased-abstract-fulltext` (the code calls it ClinicalBERT), frozen, CLS token → 768 |
| Structured encoder | 3-layer MLP on 44 features (age, sex, 7 triage values, 18 ED vital-sign aggregates, 17 lab means) → 256. Missing values become 0. |
| Fusion | Cross-attention in both directions between the image and text vectors (8 heads, 768 dimensions) → MLP → 768; concatenated with the structured vector (1,024) → MLP → 512 |
| Heads | Linear → 12 logits; CLIP and SupCon projections → 128 |
| Losses | Asymmetric focal loss (weight 1.0; γ+ = 0, γ− = 4, negative-probability clip 0.05), CLIP-style contrastive loss between the fused and text vectors (0.3), supervised contrastive loss weighted by label overlap (0.3) |

## Training presets

`--config` picks a preset, and command-line flags override it.

**MAE** (`src/models/config.py`):

| Preset | Encoder | Decoder | Epochs | Batch |
|---|---|---|---|---|
| `debug` | ViT-Small: 384 dim, 6 blocks, 6 heads | 256 dim, 2 blocks | 10 | 8 |
| `fast` | ViT-Small: 384 dim, 12 blocks, 6 heads | 256 dim, 4 blocks | 100 | 32 |
| `base` | ViT-Base: 768 dim, 12 blocks, 12 heads | 512 dim, 8 blocks | 800 | 64 |

All three use 224 px input unless `--img-size` says otherwise, patch size 16, mask ratio 0.75, AdamW (betas 0.9 and 0.95, weight decay 0.05), a learning rate warmed up linearly over 40 epochs to 1.5e-4 and then cosine-decayed to 1e-6, and FP16 mixed precision. `config.py` also defines a `large` preset (ViT-Large, 1,600 epochs) that `train_mae.py` does not offer. The classifier always builds a ViT-Base encoder, so it needs a `base` MAE checkpoint.

**Classifier** (`train_classifier.py`; defaults in `ClassifierConfig` in `src/models/config.py`):

| Preset | Epochs | Batch | Warmup epochs | MAE frozen for | Data workers |
|---|---|---|---|---|---|
| `debug` | 2 | 4 | 1 | all epochs (100) | 0 |
| `fast` | 10 | 16 | 2 | 2 epochs | 4 |
| `base` | 50 | 16 | 5 | 5 epochs | 4 |

All three use 224 px input unless `--img-size` says otherwise, AdamW (weight decay 0.05), a learning rate warmed up linearly to 5e-5 and then cosine-decayed to 1e-6, layer-wise decay 0.9 (the early, middle and late thirds of the MAE encoder train at 0.73×, 0.81× and 0.9× the base rate, the new layers at 1×), loss weights 1.0 / 0.3 / 0.3, FP16 mixed precision, gradient clipping at norm 1.0 and seed 42.

## Outputs

Each `output/preprocessed/<cohort name>/` directory holds:

| File | Contents |
|---|---|
| `images.h5` | `/images/{idx}`: float32 `[1, H, W]` at full resolution (about 3000×2500), gzip-compressed. `/metadata/{idx}`: JSON with `study_id`, `subject_id`, `shape`, `image_path`. `/index`: Parquet bytes mapping `idx` to `study_id` and `subject_id`. |
| `structured.parquet` | One row per study. Keys `subject_id`, `study_id`; `age`, `gender`, `gender_M`; `triage_{temperature,heartrate,resprate,o2sat,sbp,dbp,pain,acuity}`; ED vitals `{temperature,heartrate,resprate,o2sat,sbp,dbp}_{mean,min,max,std,count}`; labs `lab_{test}_{mean,min,max,count}`; `num_ed_diagnoses`, `num_hospital_diagnoses`, `num_procedures`; flags `has_triage`, `has_labs`, `has_ed_vitals`. |
| `text.parquet` | `subject_id`, `study_id`, `report`, `report_clean`, `clinical_context`, `summary`, `tokens` (comma-separated token IDs), `token_count`, `has_report`. With `--leak-free`, `report` and `report_clean` are empty and `has_report` is false. |
| `image_results.parquet` | Image status per study: `success`, `error`, `shape` |
| `manifest.json` | Counts and timing per modality |

The 17 lab tests are bicarbonate, BNP, BUN, calcium, chloride, creatinine, glucose, hematocrit, hemoglobin, lactate, magnesium, platelets, potassium, procalcitonin, sodium, troponin and WBC.

Missing labs and vitals stay NaN in `structured.parquet`, the `has_*` flags record which groups exist, and the classifier turns NaN and infinite values into 0. The `NOT_DONE` token for missing values belonged to the first preprocessing code (`step2_preprocessing`), which the current `src/preprocessing/` replaced in November 2025.

Models go to `output/models/` (`mae_final.pt`, `mae_best.pt`, `anomaly_detector.pt`, `classifier_best.pt`, `classifier_final.pt`, with their configs and histories) and checkpoints to `output/checkpoints/`. The production files were `classifier_best.pt` (942 MB), `classifier_final.pt` (890 MB) and `mae_final.pt` (447 MB).

## Running on a GPU

The production run used Lambda Cloud's `gpu_1x_gh200` instance: one NVIDIA GH200 480GB (about 97 GB of GPU memory) with Ubuntu 22.04 and CUDA 12, at $1.50 per hour. Setup on the instance, as in `setup_lambda.sh`:

```bash
python3 -m venv venv && source venv/bin/activate
pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu126   # CUDA 12.6 build first
pip install -r requirements.txt
```

Copy the code and the preprocessed data over with `rsync`, run training under `nohup` with a log file, watch it with `tail -f` and `nvidia-smi`, copy the checkpoints back with `scp`, and terminate the instance. For the production run the data went over already preprocessed (225 GB compressed, about 2 hours), and Claude summarization was off, so there was no API cost.

| Job | Time | Cost |
|---|---|---|
| Production classifier: 50 epochs, 1024 px, batch 16 | ~36 h | ~$54 |
| Validation run: 200 studies, `fast` preset, 40 epochs, batch 2, 1024 px | ~25 min | ~$0.63 |
| MAE `base`, 1024 px, batch 4, 30,107 training samples | ~38 min per epoch (800 epochs ≈ 21 days) | $1.50 per hour |

GPU memory at 1024 px:

- MAE ViT-Small: ~8 GB at batch 2, ~15 GB at batch 4, ~22 GB at batch 6.
- MAE ViT-Base: ~35 GB at batch 2, ~68 GB at batch 4; batch 6 runs out of memory.
- Classifier at batch 16: ~28 GB with the MAE frozen, ~90 GB with it unfrozen.

## Training stability

Classifier training in December 2025 failed until four fixes went in:

- **What broke.** In the 17 December 2025 run, a weight corruption in epoch 2 triggered recovery code that created a new `GradScaler()`. The new scaler was out of sync with the optimizer, every later batch failed, and the circuit breaker stopped epochs 3-29 after 9 batches each. Two of 30 epochs trained, and the best validation macro AUROC was 0.650.
- **Fix 1, GradScaler reset (`train_classifier.py`).** Recovery resets the existing scaler with `scaler.load_state_dict(...)` and clears the optimizer state. This removed the cascade.
- **Fix 2, cross-attention guards (`CrossAttentionFusion`).** Inputs pass through `torch.nan_to_num` and are clamped to `[-10, 10]`, and the attention outputs and the fused vector pass through `nan_to_num` again.
- **Fix 3, safe normalization.** `safe_normalize()` replaces `F.normalize()` in the projection heads and in the CLIP and SupCon losses, where zero-norm vectors produced NaN.
- **Fix 4, MAE epsilon (`src/models/mae.py`).** The normalized-pixel loss uses ε = 1e-5 instead of 1e-6, for FP16.

Training also computes the losses in FP32, skips batches with a non-finite loss, reverts the weights to the last good copy after a corruption, ends an epoch after 10 corruptions in a row, caps the CLIP logit scale at 100 and clips gradients at norm 1.0. The dataset excludes 8 studies that produced NaN.

The production run completed 50 of 50 epochs with under 0.5% of batches skipped for NaN, no weight corruptions and no circuit-breaker stops (28 before the fixes). The 200-study validation run before it had no NaN batches in 40 epochs, and its loss fell from 0.524 to 0.254.

## Results

### Classifier

The production model (December 2025) trained for 50 epochs on the 27,576 training studies. On the 4,922 validation studies, all from the abnormal cohort, it reached macro AUROC 0.701 and macro AUPRC 0.899 over the 12 classes. The run used 1024 px center crops, batch 16, AdamW with weight decay 0.05, FP16 mixed precision and gradient clipping at 1.0.

| Class | AUROC | AUPRC | Labeled studies | Positive |
|---|---|---|---|---|
| Edema | 0.878 | 0.934 | 1,237 | 68.1% |
| Consolidation | 0.840 | 0.825 | 599 | 42.9% |
| Pleural Effusion | 0.821 | 0.928 | 1,777 | 75.3% |
| Pneumothorax | 0.812 | 0.672 | 730 | 23.6% |
| Cardiomegaly | 0.808 | 0.965 | 1,334 | 88.3% |
| Pneumonia | 0.751 | 0.837 | 987 | 61.4% |
| Lung Opacity | 0.717 | 0.990 | 2,022 | 97.9% |
| Enlarged Cardiomediastinum | 0.708 | 0.793 | 271 | 60.5% |
| Fracture\* | 0.651 | 0.948 | 230 | 91.3% |

"Labeled studies" counts the validation studies with a 0 or 1 for that class. The class names are corrected: the original report listed the last four classes under names shifted by one ([below](#what-v2-found-about-v1s-evaluation)). AUPRC mostly tracks prevalence, since 10 of the 12 classes are 60-99% positive in this abnormal-only cohort. At a 0.5 threshold the model favored recall: 10 of 12 classes had recall above 0.9.

### MAE reconstruction error

On the anomalous validation images (January 2026; 1024 px center crops, 75% masking), the reconstruction MSE by pathology, in units of 10⁻⁴, was: Pleural Other 9.07, Pneumothorax 8.73, Pneumonia 8.67, Fracture 8.64, Lung Lesion 8.16, Edema 8.14, Atelectasis 6.22, Pleural Effusion 6.18, Lung Opacity 5.44, Cardiomegaly 5.11, Enlarged Cardiomediastinum 5.09, Support Devices 4.18, Consolidation 3.56.

## What v2 found about v1's evaluation

v2 started from a code review of v1 (on branch `claude/gifted-lovelace-1vr4rs`). Its findings are below; [ANALYSIS.md, From v1 to v2](ANALYSIS.md#from-v1-to-v2) explains what v2 changed in response to each.

- **Shifted class names.** The original per-class table had its last four names shifted by one: its No_Finding, Pleural_Effusion, Pleural_Other and Pneumonia rows are Pleural Effusion, Pleural Other, Pneumonia and Pneumothorax. v2 checked this against MIMIC-CXR's published label statistics. The table above uses the corrected names.
- **Four classes are noise.** Fracture, Lung Lesion, Atelectasis and Pleural Other rest on 2-23 negative studies each in the validation set. On the other 8 classes, each with at least 30 negatives, v1 averages 0.792.
- **Three choices can inflate that 0.792.** Labs drawn after the X-ray (the lab window runs to 24 hours after it); discharge diagnosis codes in the text (the clinical context lists hospital diagnosis codes); and the best epoch picked on the reported set (`classifier_best.pt` is the epoch with the best AUROC on the same 4,922 validation studies).
- **A narrow cohort.** The anomalous cohort holds 32,498 of MIMIC-CXR's 138,707 abnormal studies (23.4%). For patients with ED visits, only studies within 24 hours of one stay in, and the `StudyTime` parse (`str[:6]`) fails for times before 10:00, so those studies drop out: 0.01% of the cohort was taken before 10:00, against 51.8% of the abnormal studies outside it.
- **Side views in training.** The file-name rule for picking a frontal view never matches MIMIC-CXR's file names, which are DICOM IDs, so 31.3% of the training images were lateral.
- **v2's bar.** v2 took about 0.79 on those 8 classes as v1's level and made a clean number its primary goal.

## Known issues in the code

- The text branch tokenizes with Bio_ClinicalBERT's vocabulary (`src/config/settings.py`) but encodes with PubMedBERT (`src/models/multimodal.py`), whose vocabulary differs, so the classifier reads mismatched token IDs.
- `text_clip_proj` and the CLIP loss's `logit_scale` are in no optimizer group, so they never train.
- The cross-attention fusion gets one image vector and one text vector. With a single item to attend to, each attention step reduces to a fixed linear map, so it can't weigh one part of the image or the text over another.
- `detect_anomalies.py --detector` is parsed but never used.
